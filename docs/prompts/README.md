# AI Specialist Capstone — 7 Practical Kiro Prompts

This prompt pack is the streamlined execution path for the bookstore capstone.

It replaces the much larger 23-prompt reference sequence with the minimum practical workflow needed to complete the assignment using:

- AWS Kiro
- Java 21
- Spring Boot 3.x
- Maven
- PostgreSQL
- OpenAPI
- JUnit / Spring Boot Test
- Git/GitHub
- Postman or Insomnia
- Local execution

## Sequence

1. Requirements Analysis
2. PostgreSQL Data Model Design
3. API Design + OpenAPI
4. Spring Boot Backend Implementation
5. PostgreSQL Configuration + Local Run
6. Testing + API/OpenAPI Validation
7. Final Review + GitHub + Demo Readiness

## Working Rule

Run one prompt at a time. Review and approve the artifact from each phase before moving to the next prompt.

AWS hosting, Docker, Kubernetes, CloudFormation, ECR, App Runner, and CI/CD are intentionally excluded from the minimum capstone path unless explicitly added later.
